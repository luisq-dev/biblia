# Componentes y licencias de terceros

## Tipografías

- **Literata:** `assets/fonts/OFL.txt` (SIL Open Font License 1.1).
- **Liberation Sans y Liberation Serif:** `assets/fonts/Liberation-LICENSE.txt` (SIL Open Font License 1.1).

Sus archivos de licencia se conservan y se pueden consultar dentro de Ajustes.

## Flutter y paquetes Dart

Flutter, Provider, Shared Preferences, Path Provider y Share Plus mantienen sus propias licencias. La aplicación incluye la página de licencias de código abierto generada por Flutter. Las versiones exactas se fijan en `pubspec.lock`.

## Texto bíblico RVR1960

El texto RVR1960 y sus marcas pertenecen a sus titulares; no se les asigna la licencia del código de esta app. Los metadatos locales que declaran uso personal no acreditan por sí mismos autorización de redistribución pública.

Antes de publicar el texto completo o un APK que lo incorpore, el mantenedor debe contar con la autorización correspondiente. Consulta las [condiciones del titular](https://bibles.com/pages/american-bible-society-rights-and-permissions). No incluyas documentos privados de autorización, datos de contacto personales o contratos en este repositorio público.

## Código de la aplicación

El titular todavía no ha elegido una licencia de software para el código propio. Que el repositorio sea público no concede por sí solo una licencia de reutilización. No se declara este proyecto como MIT ni se relicencian contenidos de terceros.
